# 56 Continuation of Gazette notices made for Network Access Code
(1) On 1 July 2015, an ongoing notice becomes a Gazette notice under the provision of the Network Access Code for the purposes of which it was made.
(2) In this section:
ongoing notice means a Gazette notice made under former section 7 for the purposes of a provision of the Network Access Code that was in force immediately before 1 July 2015.
