# 2A Application to NAC electricity networks
(1) This Code applies in relation to an NAC electricity network.
(2) In this Code:
(a) a reference to an electricity network is a reference to an NAC electricity network; and
(b) a reference to a network provider, network user, system controller or other electricity entity is a reference to a person or entity of that kind that uses an NAC electricity network.
