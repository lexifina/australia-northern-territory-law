# 26 Orders for disconnection in certain circumstances where there is no breach
(1) The Supreme Court, on application by the regulator on behalf of the Commonwealth, may make an order requiring the physical disconnection of a network participant's connection points if a relevant disconnection event occurs.
(2) In this section:
relevant disconnection event means an event specified in the Network Access Code as being an event for which a network participant's connection points may be disconnected, being an event that does not constitute a breach of this Act.
