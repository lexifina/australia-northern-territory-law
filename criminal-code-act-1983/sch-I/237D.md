# 237D Events and event contingencies
(1) An event means any event (whether it takes place in the Territory or elsewhere) on which it is lawful to bet under the laws of the Territory, a State, another Territory or the Commonwealth.
(2) An event contingency means any contingency:
(a) that is connected in any way with an event; and
(b) on which it is lawful to bet under the laws of the Territory, a State, another Territory or the Commonwealth.
