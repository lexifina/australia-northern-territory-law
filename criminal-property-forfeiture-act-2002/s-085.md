# 85 Assessing the value of crime-used property
(1) When assessing the value of crime-used property for the purposes of making a crime-used property substitution order, the value of the property is taken to be its value at the time that the relevant forfeiture offence was or is likely to have been committed.
(2) The value of the crime-used property is taken to be its full value even if the respondent did not outlay any amount for the purpose of obtaining or making criminal use of the property or did not outlay an amount equal to its full value for that purpose.
