# 50 Establishment of control program
(1) The Minister may, by Gazette notice, establish a disease control program for the control of a disease specified in the notice.
(2) The notice must include the following information:
(a) if the specified disease is a notifiable disease – its classification as an emergency disease, endemic disease or exotic disease;
(b) the livestock, including travelling livestock, to which the control program applies (controlled livestock);
(c) the area to which the control program applies (the program area).
(3) For subsection (2)(c), the program area for a control program may be one or more areas of the Territory or the whole of the Territory.
