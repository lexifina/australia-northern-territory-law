# 58 Separate indefeasible titles for tenants in common
(1) If a lot is, or is to be held, by 2 or more registered owners as tenants in common, the Registrar-General may create a separate indefeasible title for the interest of each owner by including a separate set of particulars in the land register for the interest of each owner.
(2) The Registrar-General may act under this section at the request of an owner.
