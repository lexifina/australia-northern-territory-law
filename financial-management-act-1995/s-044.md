# 44 References to Allocation
(1) Subsection (2) applies if:
(a) a provision of an Act expressed or expresses an idea by using "Allocation"; and
(b) the provision is amended and uses "appropriation".
(2) The ideas must not be taken to be different merely because a different word is used.
(3) In a document, a reference to "Allocation" is taken to be a reference to "appropriation" if the context permits.
