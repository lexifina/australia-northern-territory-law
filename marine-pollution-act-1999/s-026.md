# 26 Interpretation
(1) In this Part:
harmful substance means those substances that are identified as marine pollutants in the International Maritime Dangerous Goods Code.
International Maritime Dangerous Goods Code means the Code adopted by the International Maritime Organisation by resolution A.716(17) as amended from time to time.
jettisoning includes leakage and accidental discharge or loss overboard.
packaged form means a form of containment specified for harmful substances in the International Maritime Dangerous Goods Code.
(2) An amendment to the International Maritime Dangerous Goods Code is of no effect until the Minister has published in the Gazette a notice that the particular amendment is to be taken to be part of the Code.
(3) The Minister may publish in the Gazette a notice that an amendment to the International Maritime Dangerous Goods Code is to be taken to be part of the Code for the purposes of this Act.
