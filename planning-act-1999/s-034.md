# 34 Existing uses protected
(1) Subject to subsection (2), a person does not contravene the development provisions by reason only of continuing an existing use after the commencement of an amendment of the development provisions that is an amendment with which the use conflicts.
(2) A person may continue an existing use only if:
(a) the use is restricted to the part of the land on which the use took place immediately before the commencement of the amendment of the development provisions that is an amendment with which the use conflicts; and
(b) the intensity of the use is not greater than the intensity of use immediately before the commencement of the amendment of the development provisions that is an amendment with which the use conflicts.
